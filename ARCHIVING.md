# Version archiving

Release: `v0.1.0-dev7`; Python package version: `0.1.0.dev7`; license: MIT.

No DOI is assigned by Git tags, GitHub Releases or this metadata file. A real
Zenodo publication is required. There is deliberately no placeholder DOI badge.

To enable future automatic archives, sign in to https://zenodo.org with GitHub,
open the GitHub integration settings, grant access and enable this repository
**before creating the next release**. Existing releases are not backfilled.

For this release, upload the release source ZIP and the two wheels to a new
Zenodo software record. Use the metadata in `.zenodo.json`, preserve the exact
version and source commit, and verify authorship/license. After publication,
record the **version DOI** in `CITATION.cff`, README and manuscript. A later docs
commit can add the DOI without moving the archived version tag.

Instructions: https://help.zenodo.org/docs/github/
Versioning: https://zenodo.org/help/versioning

An archived software DOI is not journal publication or a journal retrieval certificate.
